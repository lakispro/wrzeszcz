# Wrzeszcz Dolny w fotografii

Strona https://wrzeszcz.lakis.pro — zdjęcia budynków i otoczenia Wrzeszcza Dolnego (Gdańsk, niem. Langfuhr) z opisami, datami i źródłami.

- `docs/index.html` — strona (statyczna, GitHub Pages)
- `docs/data.json` — dane zdjęć (źródło, autor, licencja, data, współrzędne)
- `docs/boundary.geojson` — granica dzielnicy z OpenStreetMap (relacja 2642963)

Zdjęcia nie są kopiowane do repozytorium — wyświetlane są z serwisów źródłowych (Wikimedia Commons i in.) z podaniem autora i licencji.
